# SysInner HTTP Load Balancer

**This project is archived**

This repository is no longer maintained as a standalone project. The HTTP
load balancer code has been migrated into
[github.com/sysinner/innerstack](https://github.com/sysinner/innerstack) as a
built-in module named **ingate**, where it continues to be developed and
maintained.

For the latest code, bug reports, and contributions, please head to the
[innerstack](https://github.com/sysinner/innerstack) repository
([ingate](https://github.com/sysinner/innerstack/tree/main/cmd/ingate) module).

---
